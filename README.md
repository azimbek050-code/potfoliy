## 📖 About the project

**GoTrip** is a responsive landing page for a store that serves hikers, climbers and travelers, from large expeditions to small groups of tourists. The idea behind the store is simple: *safety comes first*, and the right equipment protects you from injury, overheating and frostbite.

This project was built as part of my web development portfolio.

## ✨ Features

- 🧭 **Clear navigation:** quick access to About us, Catalog and Contacts
- 🔎 **Search field** in the header
- 🛍️ **Product catalog** with 4 categories:
  - 👕 Clothes
  - 🥾 Shoes
  - ⛺ Tents
  - 🎒 Backpacks
- 📞 **Contact section** for product availability and delivery requests
- 🚀 **Deployed on Netlify**
